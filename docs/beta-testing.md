# Beta Testing Program

Get early access to Streamyfin's latest features and help shape the future of the app.

## Overview

The Streamyfin Beta Testing Program gives you access to cutting-edge features before they're released to the general public. Beta testers play a crucial role in helping us identify bugs, test new functionality, and ensure the best possible experience for all users.

## How to Join Beta

### Patreon Subscription Required

To access Streamyfin beta releases, you need to subscribe to the **Member tier** (or higher) on our [Patreon](https://www.patreon.com/streamyfin).

#### Benefits of Membership:
- 🧪 Immediate access to beta releases
- 💬 Access to exclusive Discord beta channels
- 🔥 First look at new features
- 🎯 Direct feedback channel to developers
- 🏆 Recognition as a supporter

#### Active Contributors Exception:
Anyone actively contributing to Streamyfin's source code receives automatic access to beta releases without requiring a Patreon subscription.

### Setup Process

#### Step 1: Subscribe to Patreon
1. Visit [Streamyfin Patreon](https://www.patreon.com/streamyfin)
2. Choose **Member tier** or higher
3. Complete subscription process

#### Step 2: Join Discord
1. Join our [Discord server](https://discord.gg/BuGG9ZNhaE)
2. Your Patreon subscription will automatically grant access to:
   - `#🧪-beta-releases` channel
   - `#💬-beta-chat` channel
   - Special beta tester role

#### Step 3: Platform-Specific Setup

**For iOS (TestFlight):**
1. Install [TestFlight](https://apps.apple.com/app/testflight/id899247664) from App Store
2. Send a DM to `@Cagemaster` on Discord with:
   - Your Apple ID email address
   - Confirmation of Patreon subscription
3. Wait for manual TestFlight invitation
4. Accept invitation and install beta via TestFlight

**For Android:**
1. Download APK files directly from `#🧪-beta-releases` channel
2. Enable "Install unknown apps" in Android settings
3. Install APK and launch app

## Beta Version Management

### 🔄 Installation Process

**iOS (TestFlight):**
1. Open TestFlight app
2. Find Streamyfin beta
3. Tap "Install" or "Update"
4. Launch updated version

**Android (APK):**
1. Download APK from Discord
2. Uninstall previous beta (if needed)
3. Install new APK
4. Launch and test

### 📋 Version Tracking

**Beta version numbering:**
- Format: `0.30.0-beta.1`
- Major.Minor.Patch-beta.Build
- Each beta increments build number

**Release Notes:**
- Available in Discord channel
- Lists new features and fixes
- Includes known issues
- Testing focus areas

### 🔄 Rollback Options

**If beta has issues:**
- Keep stable version installed
- Report issues immediately
- Wait for hotfix or next beta
- Provide feedback to help fix

## Beta Testing Best Practices

### 📝 Effective Testing

**Test systematically:**
1. **Daily Usage**: Use as primary app
2. **Feature Focus**: Test new features thoroughly
3. **Edge Cases**: Try unusual scenarios

## FAQ

### ❓ Common Questions

**Q: How often are beta versions released?**
A: Weekly during active development, with hotfixes as needed.

**Q: Can I use beta as my main app?**
A: We recommend keeping the stable version as backup.

**Q: What happens if I cancel Patreon?**
A: Beta access continues until subscription expires, then you'll need to use stable versions.

**Q: Can I share beta versions?**
A: No, beta versions are exclusive to subscribers and contributors.

**Q: How do I report critical issues?**
A: Use Discord beta chat for immediate developer attention.

### 🔧 Troubleshooting

**Common beta issues:**
- **App won't install**: Check Android settings, clear cache
- **Crashes on startup**: Report immediately with device info
- **TestFlight not working**: Contact @Cagemaster directly
- **Missing features**: Check if feature is in current beta
