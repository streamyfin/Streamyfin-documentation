# Streaming and Playback

Master the art of streaming with StreamyFin's powerful playback features.

## Starting Playback

### Browse Your Content

Navigate through your media library:
- **Movies**: Browse by genre, year, or rating
- **TV Shows**: Organized by series and seasons
- **Music**: Browse by artist, album, or genre
- **Search**: Find specific content quickly

### Play Controls

**Basic Controls:**
- Tap to play/pause
- Swipe left/right for seek
- Volume controls on side
- Brightness adjustment

**Advanced Controls:**
- Double-tap sides for skip forward/backward
- Long press for speed controls
- Pinch to zoom (where supported)
- Gesture controls customization

## Video Playback Features

### Quality Selection

StreamyFin automatically adjusts quality based on:
- Network speed and stability
- Device capabilities
- Server transcoding capacity
- User preferences

**Manual Quality Control:**
1. Tap the gear icon during playback
2. Select "Quality"
3. Choose from available options:
   - Original (direct play)
   - 1080p, 720p, 480p
   - Custom bitrates

### Subtitle Management

**Enabling Subtitles:**
1. Tap the "CC" icon during playback
2. Select your preferred language
3. Adjust subtitle settings if needed

**Subtitle Customization:**
- Font size and color
- Background opacity
- Position on screen
- Encoding selection

### Audio Tracks

**Switching Audio:**
1. Tap the audio icon during playback
2. Choose from available audio tracks
3. Select preferred language or format

**Audio Features:**
- Multi-channel audio support
- Audio boost options
- Sync adjustment controls
- Codec information display

## Music Playback

### Music Player Interface

**Now Playing Screen:**
- Album artwork display
- Progress bar and time
- Shuffle and repeat controls
- Volume and audio settings

**Playlist Management:**
- Add to queue
- Create custom playlists
- Shuffle play options
- Repeat modes (off, one, all)

### Background Playback

Music continues playing when:
- App is in background
- Screen is locked
- Using other apps
- Device is in sleep mode

**Lock Screen Controls:**
- Play/pause button
- Skip forward/backward
- Track information
- Album artwork

## Advanced Playback Features

### Chapter Navigation

For content with chapters:
- Tap the chapter icon
- Select from chapter list
- Auto-skip intro/outro (if configured)
- Bookmark favorite chapters

### Playback Speed

Adjust playback speed:
- 0.5x to 3x speed options
- Pitch correction toggle
- Speed memory per content type
- Gesture shortcuts

### Picture-in-Picture (iOS)

Continue watching while using other apps:
1. Start video playback
2. Swipe up to home screen
3. Video continues in small window
4. Tap window to return to full screen

### Resume and Sync

**Cross-Device Resume:**
- Automatically saves playback position
- Syncs across all devices
- Resume from any StreamyFin client
- Manual sync triggers available

**Watch Status:**
- Mark as watched/unwatched
- Tracking progress percentage
- Recently watched history
- Continue watching shortcuts

## Troubleshooting Playback

### Common Issues

**Video Won't Play:**
- Check internet connection
- Verify server is accessible
- Try different quality setting
- Restart the app

**Audio/Video Sync Issues:**
- Pause and resume playback
- Try different audio track
- Check source file quality
- Report persistent issues

**Stuttering or Lag:**
- Lower playback quality
- Close other apps
- Check device storage
- Restart device if needed

### Performance Tips

**Optimize Experience:**
- Use WiFi when possible
- Keep app updated
- Clear cache regularly
- Manage storage space
- Close unused apps

**Quality vs Performance:**
- Balance quality with device capabilities
- Monitor data usage on mobile
- Adjust settings per network type
- Use hardware acceleration when available
