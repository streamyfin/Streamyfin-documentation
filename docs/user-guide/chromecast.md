# Chromecast and TV Streaming

Stream your content to the big screen with seamless Chromecast integration.

## Getting Started with Chromecast

### Device Requirements

**Supported Chromecast Devices:**
- Chromecast (3rd generation and later)
- Chromecast with Google TV
- Chromecast Ultra
- Google Nest Hub displays
- TVs with built-in Chromecast

**Network Requirements:**
- Same Wi-Fi network for phone and Chromecast
- Stable internet connection
- Sufficient bandwidth for chosen quality

### First Time Setup

1. **Ensure Chromecast is Ready:**
   - Plugged into TV and powered on
   - Connected to same Wi-Fi network
   - Google Home app setup completed

2. **Connect from StreamyFin:**
   - Start playing content in StreamyFin
   - Tap the cast icon (📺)
   - Select your Chromecast device
   - Wait for connection confirmation

## Troubleshooting Casting

### Connection Issues

**Can't Find Chromecast:**
- Verify same Wi-Fi network
- Restart Chromecast device
- Check Google Home app
- Reset network settings if needed

**Casting Keeps Disconnecting:**
- Check Wi-Fi signal strength
- Restart router if necessary
- Update Chromecast firmware
- Reduce network interference

### Playback Problems

**Video Won't Start:**
- Check server connectivity
- Try different content
- Restart both devices
- Verify content format support

**Audio/Video Issues:**
- Check HDMI connections
- Try different quality setting
- Restart casting session
- Update TV firmware

**Lag or Buffering:**
- Reduce streaming quality
- Check network bandwidth
- Close other streaming devices
- Move closer to router
