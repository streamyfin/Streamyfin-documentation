# Installation

Learn how to install StreamyFin on your device.

## iOS Installation

### App Store (Recommended)

1. Open the App Store on your iOS device
2. Search for "StreamyFin"
3. Tap "Get" to download and install
4. Once installed, tap "Open" to launch the app

### TestFlight (Beta)

For beta versions and early access:

1. Download TestFlight from the App Store if you haven't already
2. Join the StreamyFin beta program (link will be provided)
3. Install via TestFlight

## Android Installation

### Google Play Store

1. Open Google Play Store on your Android device
2. Search for "StreamyFin"
3. Tap "Install"
4. Launch the app once installation is complete

### APK Installation

For direct APK installation:

1. Download the latest APK from our releases page
2. Enable "Unknown sources" in your device settings
3. Install the APK file
4. Launch the app

## System Requirements

### iOS
- iOS 13.0 or later
- Compatible with iPhone, iPad, and iPod touch

### Android
- Android 7.0 (API level 24) or later
- ARM64 or x86_64 processor architecture
