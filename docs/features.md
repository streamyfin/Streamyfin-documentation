# Features

Discover all the powerful features that make StreamyFin the best Jellyfin client for mobile devices.

## Core Features

### 🎥 Video Streaming
- **High-quality streaming** with adaptive bitrate
- **Multiple format support** including H.264, H.265, VP9
- **Hardware acceleration** for smooth playback
- **Subtitle support** with multiple language options
- **Chapter navigation** for easy content browsing

### 🎵 Music Playback
- **Lossless audio streaming** for audiophiles
- **Playlist management** and creation
- **Background playback** while using other apps
- **Artist and album browsing**
- **Lyrics display** (when available)

### 📱 Mobile Optimized
- **Native iOS and Android** interfaces
- **Touch-friendly controls** designed for mobile
- **Picture-in-Picture** support (iOS)
- **Background audio** playback
- **Lock screen controls**

## Advanced Features

### 🔄 Sync and Download
- **Offline downloads** for watching without internet
- **Sync progress** across all devices
- **Resume playback** from where you left off
- **Download management** with quality options

### 🎮 Chromecast Support
- **One-tap casting** to Chromecast devices
- **Remote control** your TV playback from phone
- **Queue management** while casting
- **Subtitles on TV** with full control

### 🔍 Discovery
- **Advanced search** across your entire library
- **Recommendations** based on viewing history
- **Continue watching** quick access
- **Recently added** content highlights

### ⚙️ Customization
- **Theme options** including dark mode
- **Playback settings** customization
- **Quality preferences** per network type
- **Parental controls** and user profiles

## Integration Features

### 📊 Rich Metadata
- **Detailed information** for movies and shows
- **Cast and crew** information
- **Ratings and reviews** from multiple sources
- **Artwork and fanart** in high resolution

### 🔗 External Services
- **Seerr integration** for content requests
- **JellySearch** for enhanced search capabilities
- **Plugin support** for extended functionality
- **Third-party service** connections
