# Features

Discover all the powerful features that make Streamyfin the best Jellyfin client for mobile devices.

## Core Features

### 🎥 Video Streaming
- **High-quality streaming** with adaptive bitrate
- **Multiple format support** including H.264, H.265, VP9
- **Hardware acceleration** for smooth playback
- **Subtitle support** with multiple language options and customization
- **Chapter navigation** for easy content browsing
- **Trickplay images** for visual seeking previews

### 📥 Media Downloads
- **Offline downloads** for watching without internet
- **Background downloads** - app doesn't need to stay open
- **Quality options** for downloads
- **Download management** with progress tracking
- **HLS stream conversion** for compatibility

### 🚀 Skip Intro/Credits
- **Automatic skip intro** detection and jumping
- **Skip credits** at episode end
- **One-tap skip** buttons during playback
- **Server-side detection** for accuracy

### 📱 Mobile Optimized
- **Native iOS and Android** interfaces
- **Touch-friendly controls** designed for mobile
- **Picture-in-Picture** support (iOS)
- **Lock screen controls**
- **Gesture navigation**

## Advanced Features

### 📡 Chromecast Support
- **One-tap casting** to Chromecast devices
- **Video casting** with remote control
- **Queue management** while casting
- **Subtitle support** (in development)

### 🤖 Seerr Integration
- **Direct content requests** from within the app
- **Automatic login** with Streamyfin plugin
- **Request status tracking**
- **Browse available content**

### 🔍 Enhanced Search
- **JellySearch integration** for full-text search
- **Fast search results** across your entire library
- **Advanced filtering** options
- **Search suggestions** and autocomplete

### 👥 Session Management
- **View active sessions** on your server
- **Monitor streaming activity** (admin users)
- **Session details** including device and user info
- **Remote session control** capabilities

### ⚙️ Plugin-Based Settings
- **Centralized configuration** via Jellyfin plugin
- **Synchronized settings** across all devices
- **Default user preferences** set by admin
- **Custom home screen** layouts
